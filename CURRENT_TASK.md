  - `assembly-core.js`: API занятости — `findFreeSlotNear()` (ближайший свободный слот в

    → `_snapToSlot()` ставит деталь в позу слота (world→local), `type: kinematic`, state `snapped`;
    tick для `snapped` делает early-return. Серый мусор идёт по старой ветке gravity/float.
  - **Ручной разбор снепа** (по запросу пользователя): `floating-cube._onStateAdded` ловит
    переход в `grabbed-dynamic` у снепнутой детали → `_unsnapFromSlot()` (освобождает слот,
    `type: dynamic`). Нужно, чтобы можно было переставить ошибочно поставленную деталь
    (в будущем — детали-обманки), не дожидаясь удара шара. Реализовано одним файлом,
    `physx-grab.js` не тронут.
    ✅ **РИСК kinematic↔kinematic снят:** на Quest захват снепнутой детали РАБОТАЕТ
    (первый un-snap сработал) → контакт kinematic↔kinematic в этом биндинге генерится.
  - 🐞 **Фикс повторного снепа (защёлка `setKinematic`):** `@c-frame/physx@0.3.0`
    выставляет флаг `eKINEMATIC` в `tock()` один раз через защёлку `this.setKinematic`,
    которую назад НЕ сбрасывает (physics.js ~стр.1257). Из-за этого ПОВТОРНЫЙ снеп
    (после un-snap) не становился настоящим kinematic: тело оставалось dynamic, визуал
    расходился с физ-телом → объекты проходили насквозь и деталь нельзя было снова взять.
    Лечение: `floating-cube._resetKinematicLatch()` сбрасывает `setKinematic=false` при
    возврате в dynamic (в `_unsnapFromSlot`). ✅ Занесено в ADR-02 п.7 (с.33).

## Доп. задача (с.33 → следующая сессия): шары в круглой комнате не ломают башню

**Симптом:** после перехода на круглый купол (ADR-20) красные шары большую часть времени
просто катаются внизу по полу вдоль стенки купола. Оттолкнуться им не от чего → к башне/
снепам не возвращаются → угроза не работает (свою функцию «ломать сборку» не выполняют).

**Что НЕ делать сразу:** не лезть в код до согласования. Сначала — **предложить
варианты решения** (например: возвращающий импульс/хоминг к ядру при долгом «качении» у пола;
лёгкая псевдогравитация к центру купола; минимальная вертикальная составляющая скорости;
зона-отражатель у пола; периодический «пинок» к башне), оценить элегантность/риски, выбрать с
пользователем, затем реализовать микро-шагами. Числа — в `CONFIG.balls`.
**Файлы (вероятно):** `red-ball.js`, `config.js`. НЕ трогать без нужды: купол/слои.
